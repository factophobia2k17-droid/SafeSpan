How SafeSpan works

A usage-based indicator is built into every utensil. It works without electricity, apps or manual tracking.

1

Feed and wash as usual

Nothing to set up. It’s used like any other baby spoon, bowl or sipper.

2

The indicator changes color

It moves from safe to unsafe as the utensil is used. The change is permanent, so it can’t be reset.

3

Replace when it tells you

When it shows unsafe, swap it for a fresh one. A replacement pack is always available.
